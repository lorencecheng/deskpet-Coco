# 🐾 DeskPet Coco — 咖啡猫桌面宠物

An open-source desktop pet that lives on your computer screen. 一只灵动可爱的 **咖啡猫**（橘黄胖猫）桌面宠物。

## ✨ Features

- **Always-on-top** — 宠物常驻桌面最上层，边工作边陪你
- **Always-on-top 任意位置** — 直接用鼠标拖拽宠物，把它放到屏幕任意角落
- **八大互动**（右键点击宠物或托盘菜单触发）：
  - 😺 **说嗨** — 挥挥爪子跟你打招呼
  - ☕ **喝咖啡** — 捧杯小口喝，惬意享受（咖啡猫本猫）
  - 🍝 **喂意大利宽面** — 咖啡猫的最爱，吧唧吧唧吃得很香
  - 🧶 **玩毛线球** — 扑来扑去追毛线球，超灵动
  - 🐱 **追光标** — 压低身子朝你的鼠标猛地扑过去
  - 🛁 **洗澡** — 泡在泡泡浴里舒服享受
  - 🎣 **钓鱼** — 举起鱼竿，钓起一条亮晶晶的小鱼
  - 🐾 **抓痒** — 抬起后爪挠痒，一脸享受
  - 😴 **睡觉** — 蜷成一团打盹，点它一下就醒
- **灵动 AI 行为** — 会时不时眨眼、挥手、挠痒；安静久了会自己打盹睡觉
- **逐帧动画** — 每个互动状态都内置 6 帧手绘循环动画（呼吸、咀嚼、泡泡、扑跳等），真正“活”起来
- **轻量** — 基于 Electron，无边框透明窗口，资源占用低
- **形象可完全自定义** — 精灵图按 `assets/sprites/<状态>/frame-N.png` 存放，想换形象直接替换图片即可（支持逐帧动画）

## 🧠 状态系统（怎么知道猫咪想要什么）

咖啡猫有 **四项需求**，会随时间自然变化，并且会主动让你知道它现在的状态：

| 需求 | 低了会怎样 | 对应互动 |
|---|---|---|
| 🍝 饱食 | 头顶冒 🍝，气泡喊「我饿啦~」 | 喂意大利宽面 |
| 🛁 清洁 | 头顶冒 🛁，气泡喊「身上脏脏的~」 | 洗澡 |
| 😴 精力 | 头顶冒 😴，气泡喊「好困呀~」 | 睡觉（睡觉中精力持续恢复） |
| 🎈 心情 | 头顶冒 🎈，气泡喊「好无聊呀~ 陪我玩嘛~」 | 玩毛线球 / 追光标 / 说嗨 |

**三种查看方式**：

1. **对话气泡** — 需求跌破阈值时猫咪会冒出气泡提示（每项 30 秒冷却，优先提示最紧急的一项）
2. **头顶小图标** — 只要还有需求偏低，头顶会一直挂着对应的小图标（🍝🛁😴🎈）
3. **状态面板** — 右键菜单或托盘菜单点「📊 状态」，展开四条彩色进度条（绿/黄/红），数值实时更新

互动与需求的对应关系：喂宽面+饱食、洗澡+清洁、睡觉+精力、玩毛线球/追光标+心情（但会消耗精力），点击/拖拽/喝咖啡也会小幅提升心情。

## 🚀 本地运行

需要 [Node.js](https://nodejs.org) ≥ 18。

```bash
npm install     # 安装 Electron 依赖
npm start       # 启动桌面宠物
```

启动后宠物出现在屏幕右下角，你可以：

| 操作 | 效果 |
|---|---|
| 单击宠物 | 猫咪挥手说嗨 |
| 拖动宠物 | 把猫咪拎起来拖到任意位置（松手会落地弹一下） |
| 右键宠物 | 弹出互动菜单（喂宽面 / 洗澡 / 钓鱼 / 抓痒 / 睡觉） |
| 托盘图标 | 常驻系统托盘，右键可触发所有互动或退出 |

## 🗜️ 打包 Windows 可执行文件

```bash
npm run dist:win            # 生成 NSIS 安装包 + portable 免安装版
npm run dist:win:portable   # 仅生成免安装便携版（一个 .exe，双击即用）
```

产物输出到 `release/` 目录。

> 打包在 Windows 上执行最稳妥。若在其它系统打包，请参阅 [electron-builder](https://www.electron.build/multi-platform-build) 的跨平台构建说明。

## 🎨 自定义形象（把猫换成你的）

应用是 **精灵图驱动** 的，改形象不需要碰代码：

```
assets/sprites/
├── idle/        frame-1..6 …  待机（眨眼时用 idle-blink）
├── idle-blink/  frame-1 …      闭眼眨眼帧
├── happy/       frame-1..6 …  说嗨/打招呼
├── drink/       frame-1..6 …  喝咖啡
├── feed/        frame-1..6 …  吃意大利宽面
├── yarn/        frame-1..6 …  玩毛线球
├── chase/       frame-1..6 …  追光标（扑跳）
├── bath/        frame-1..6 …  洗澡
├── fishing/     frame-1..6 …  钓鱼
├── scratch/     frame-1..6 …  抓痒
├── drag/        frame-1 …      被拖起
├── sleep/       frame-1..6 …  睡觉
└── core/        frame-1 …      核心形象（README 封面等）
```

- **逐帧动画（推荐）**：把同一状态多张帧命名成 `frame-1.png`、`frame-2.png`、…（最多 12 帧），应用会自动逐帧循环播放。内置状态大多是 6 帧。
- **单帧图**：只放一张 `frame-1.png` 时，猫咪的灵动感由内置 CSS 动画（浮动/呼吸/摇摆）补足。
- **透明背景**：推荐用透明 PNG。若用带白底图，应用不会自动去底，最好先抠图。

## 🏗️ 项目结构

```
deskpet-coco/
├── assets/
│   ├── sprites/        # 精灵图（可替换）
│   └── icons/          # 托盘 / 打包图标
├── src/
│   ├── main/index.js   # 主进程：透明置顶窗口、托盘、拖动定位、IPC
│   ├── preload/index.js# 安全 IPC 桥
│   └── renderer/
│       ├── index.html
│       ├── styles.css  # 透明背景 + 灵动动画
│       └── pet.js      # 状态机、帧动画、交互
├── tools/process_sprites.py # 生成精灵图时的背景透明化脚本
├── package.json
└── README.md
```
