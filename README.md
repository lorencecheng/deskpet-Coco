# 🐾 DeskPet Coco — 咖啡猫桌面宠物

An open-source desktop pet that lives on your computer screen. 一只灵动可爱的 **咖啡猫**（橘黄胖猫）桌面宠物，采用 **16bit 柔和像素风**（星露谷式复古游戏质感）。

## ✨ Features

- **像素风形象** — 整只咖啡猫为 16bit 柔和像素风，复古游戏质感，可爱又治愈（拖拽、行走、互动全是像素动画）
- **Always-on-top** — 宠物常驻桌面最上层，边工作边陪你
- **🚶 桌面巡游** — 猫咪会沿着屏幕四条边 / 四个角落自然灵动地走来走去、走走停停，偶尔从一边悠闲逛到另一边（右键菜单或托盘菜单点「桌面巡游」触发）；走路配 6 帧逐帧精灵并随移动方向左右转身，走一阵会随机停下来伸个懒腰或东张西望再继续走，走 2~4 段后自动停下休息
- **任意位置拖拽** — 直接用鼠标拖拽宠物，把它放到屏幕任意角落；拖到屏幕最左/右边缘时猫会**藏起来**，偶尔探出头来东张西望偷看，再拽一下就出来
- **八大互动**（右键点击宠物或托盘菜单触发）：
  - 😺 **说嗨** — 挥挥爪子跟你打招呼
  - ☕ **喝咖啡** — 捧杯小口喝，惬意享受（咖啡猫本猫）
  - 🍝 **喂意大利宽面** — 咖啡猫的最爱，吧唧吧唧吃得很香
  - 🧶 **玩毛线球** — 扑来扑去追毛线球，超灵动
  - 🐱 **追光标** — 鼠标移到哪，猫就一路跑着追到哪（持续追踪 + 左右转身）
  - 🛁 **洗澡** — 泡在泡泡浴里舒服享受
  - 🎣 **钓鱼** — 举起鱼竿，钓起一条亮晶晶的小鱼
  - 🐾 **抓痒** — 抬起前爪挠痒，一脸享受
  - 😴 **睡觉** — 蜷成一团打盹，点它一下就醒
- **🤖 桌面小助理** — Coco 不只是摆造型：把文件拖到它身上，它会**把文件"吃掉"并送入回收站**（可恢复）；坐太久会**提醒你站起来活动、喝水**；还会检测你所在地区的**天气预警**提醒你注意。
- **灵动 AI 行为** — 会时不时眨眼、挥手、挠痒；安静久了会自己打盹睡觉
- **自然动作节奏** — 逐帧动画与待机小动作都调慢了节奏，动作从容不急促，观感更舒服
- **状态气泡反馈** — 猫饿了 / 脏了 / 困了 / 无聊时会自动弹出气泡提醒你陪它，互动后也会回应一句俏皮话
- **小巧身形** — 整体尺寸较初版缩小 40%，不占桌面视野
- **便捷退出** — 右键菜单或托盘菜单都有「退出」入口，随时干净退出
- **轻量** — 基于 Electron，无边框透明窗口，资源占用低
- **形象可完全自定义** — 精灵图按 `assets/sprites/<状态>/frame-N.png` 存放，想换形象直接替换图片即可（支持逐帧动画）

## 🧠 状态系统（怎么知道猫咪想要什么）

咖啡猫有 **四项需求**，会随时间自然变化，并且会主动让你知道它现在的状态：

| 需求 | 低了会怎样 | 对应互动 |
|---|---|---|
| 🍝 饱食 | 头顶冒 🍝，气泡喊「我饿啦~」 | 喂意大利宽面 |
| 🛁 清洁 | 头顶冒 🛁，气泡喊「身上脏脏的~」 | 洗澡 |
| 😴 精力 | 头顶冒 😴，气泡喊「好困呀~」 | 睡觉（睡觉中精力持续恢复） |
| 🎈 心情 | 头顶冒 🎈，气泡喊「好无聊呀~ 陪我玩嘛~」 | 玩毛线球 / 追光标 / 说嗨 |

**三种查看方式**：

1. **对话气泡** — 需求跌破阈值时猫咪会冒出气泡提示（每项 30 秒冷却，优先提示最紧急的一项）
2. **头顶小图标** — 只要还有需求偏低，头顶会一直挂着对应的小图标（🍝🛁😴🎈）
3. **状态面板** — 右键菜单或托盘菜单点「📊 状态」，展开四条彩色进度条（绿/黄/红），数值实时更新

互动与需求的对应关系：喂宽面+饱食、洗澡+清洁、睡觉+精力、玩毛线球/追光标+心情（但会消耗精力），点击/拖拽/喝咖啡也会小幅提升心情。

## 🤖 小助理功能

Coco 是你桌面上的小帮手：

- **🗑️ 吃掉文件** — 把任意文件/文件夹拖到猫身上，猫会"大口吃掉"并把它们**送入回收站**（可恢复）。适合随手清理桌面上的零碎文件。
- **🧍 久坐提醒** — 当你连续工作（一段时间内无键盘/鼠标闲置）超过阈值（默认 60 分钟），猫会伸个懒腰并弹出气泡提醒：*「已连续工作约 X 分钟啦，起来伸个懒腰、喝口水吧~」*。托盘菜单可开关。
- **🌦 天气预警** — 猫按 IP 粗略定位你所在地区，检查未来 6 小时的天气预报（Open-Meteo 免费接口，无需 API Key）。若临近有雷暴、大雨、大雪、冻雨、浓雾或极端高温/低温，会提醒你注意。托盘菜单可开关。

提醒开关在系统托盘菜单的 **「🤖 小助理提醒」** 分组里。

## 🚀 本地运行

需要 [Node.js](https://nodejs.org) ≥ 18。

```bash
npm install     # 安装 Electron 依赖
npm start       # 启动桌面宠物
```

启动后宠物出现在屏幕右下角，你可以：

| 操作 | 效果 |
|---|---|
| 单击宠物 | 猫咪挥手说嗨 |
| 拖动宠物 | 把猫咪拎起来拖到任意位置（松手会落地弹一下） |
| 右键宠物 | 弹出互动菜单（桌面巡游 / 喂宽面 / 洗澡 / 钓鱼 / 抓痒 / 睡觉 / 退出等） |
| 托盘图标 | 常驻系统托盘，右键可触发桌面巡游、所有互动或退出 |

## 🗜️ 打包 Windows 可执行文件

```bash
npm run dist:win            # 生成 NSIS 安装包 + portable 免安装版
npm run dist:win:portable   # 仅生成免安装便携版（一个 .exe，双击即用）
```

产物输出到 `release/` 目录。

> 打包在 Windows 上执行最稳妥。若在其它系统打包，请参阅 [electron-builder](https://www.electron.build/multi-platform-build) 的跨平台构建说明。

## 🎨 自定义形象（把猫换成你的）

应用是 **精灵图驱动** 的，改形象不需要碰代码：

```
assets/sprites/
├── idle/        frame-1..3 …  待机呼吸循环
├── idle-blink/  frame-1 …      闭眼眨眼帧
├── happy/       frame-1..2 …  说嗨/打招呼
├── drink/       frame-1..3 …  喝咖啡（吸饮循环）
├── feed/        frame-1..3 …  吃意大利宽面（咀嚼循环）
├── yarn/        frame-1..3 …  玩毛线球（扑球循环）
├── bath/        frame-1..3 …  洗澡（泡泡循环）
├── fishing/     frame-1 …      钓鱼
├── scratch/     frame-1 …      抓痒
├── stretch/     frame-1..3 …  伸懒腰
├── lookaround/  frame-1..3 …  东张西望
├── walk/        frame-1..6 …  走路循环
├── drag/        frame-1 …      被拖起
├── sleep/       frame-1..3 …  睡觉（呼吸循环）
└── core/        frame-1 …      核心形象（README 封面等）
```

- **逐帧动画（推荐）**：把同一状态多张帧命名成 `frame-1.png`、`frame-2.png`、…（最多 12 帧），应用会自动按该状态的帧率逐帧循环播放。走路/待机/吃喝/洗澡等核心状态都内置逐帧像素循环。
- **单帧图**：只放一张 `frame-1.png` 时，猫咪的灵动感由内置 CSS 动画（浮动/呼吸/摇摆）补足。
- **透明背景**：推荐用透明 PNG。若用带白底图，应用不会自动去底，最好先抠图（可用 `tools/process_sprites.py`）。

## 🏗️ 项目结构

```
deskpet-coco/
├── assets/
│   ├── sprites/        # 精灵图（可替换）
│   └── icons/          # 托盘 / 打包图标
├── src/
│   ├── main/index.js   # 主进程：透明置顶窗口、托盘、拖动定位、IPC
│   ├── preload/index.js# 安全 IPC 桥
│   └── renderer/
│       ├── index.html

│       └── pet.js      # 状态机、帧动画、交互

└── README.md
```
