# 🐾 DeskPet Coco — 咖啡猫桌面宠物

An open-source desktop pet that lives on your computer screen. 一只灵动可爱的 **咖啡猫**（橘黄胖猫）桌面宠物，采用 **16bit 柔和像素风**（星露谷式复古游戏质感）。

## ✨ Features

- **像素风形象** — 整只咖啡猫为 16bit 柔和像素风，复古游戏质感，可爱又治愈（拖拽、行走、互动全是像素动画）
- **Always-on-top** — 宠物常驻桌面最上层，边工作边陪你
- **🚶 桌面巡游** — 猫咪会沿着屏幕四条边 / 四个角落自然灵动地走来走去、走走停停，偶尔从一边悠闲逛到另一边（右键菜单或托盘菜单点「桌面巡游」触发）；走路配 6 帧逐帧精灵并随移动方向左右转身，走一阵会随机停下来伸个懒腰或东张西望再继续走，走 2~4 段后自动停下休息
- **任意位置拖拽** — 直接用鼠标拖拽宠物，把它放到屏幕任意角落；默认开启**屏幕边缘吸附**（拖到左/右边缘会轻轻贴边蹲坐），也可在托盘里切换回「边缘藏猫」（猫藏到屏幕边、偶尔探头偷看）
- **🖥️ 全屏自动隐藏** — 打开全屏应用（游戏 / 播放器）时，猫会悄悄藏起来不挡画面；退出全屏自动回来（托盘可开关）
- **🎛️ 透明度 / 尺寸** — 托盘里可把猫调成半透明（100% / 80% / 60%），或切换小 / 中 / 大三档尺寸，适配你的屏幕
- **灵动待机动作** — 待机时会随机眨眼、**洗脸舔爪**、**打哈欠**、挠痒（心情好动作更频繁，心情低落更安静；饿了会更主动讨食）
- **八大互动**（右键点击宠物或托盘菜单触发）：
  - 😺 **说嗨** — 挥挥爪子跟你打招呼
  - ☕ **喝咖啡** — 捧杯小口喝，惬意享受（咖啡猫本猫）
  - 🍝 **喂意大利宽面** — 咖啡猫的最爱，吧唧吧唧吃得很香
  - 🧶 **玩毛线球** — 扑来扑去追毛线球，超灵动
  - 🐱 **追光标** — 鼠标移到哪，猫就一路跑着追到哪（持续追踪 + 左右转身）
  - 🛁 **洗澡** — 泡在泡泡浴里舒服享受
  - 🎣 **钓鱼** — 举起鱼竿，钓起一条亮晶晶的小鱼
  - 🐾 **抓痒** — 抬起前爪挠痒，一脸享受
  - 😴 **睡觉** — 蜷成一团打盹，点它一下就醒
- **🤖 桌面小助理** — Coco 不只是摆造型：把文件拖到它身上，它会**把文件"吃掉"并送入回收站**（可恢复）；坐太久会**提醒你站起来活动、喝水**；还会检测你所在地区的**天气预警**提醒你注意。
- **灵动 AI 行为** — 会时不时眨眼、**洗脸舔爪、打哈欠**、挠痒；安静久了会自己打盹睡觉；还会看心情决定活泼还是安静（心情好小动作更多，低落时更安静），饿了更主动讨食
- **自然动作节奏** — 逐帧动画与待机小动作都调慢了节奏，动作从容不急促，观感更舒服
- **状态气泡反馈** — 猫饿了 / 脏了 / 困了 / 无聊时会自动弹出气泡提醒你陪它，互动后也会回应一句俏皮话
- **小巧身形** — 整体尺寸较初版缩小 40%，不占桌面视野
- **便捷退出** — 右键菜单或托盘菜单都有「退出」入口，随时干净退出
- **轻量** — 基于 Electron，无边框透明窗口，资源占用低
- **🎨 皮肤工坊** — 无需会画画也能换肤：内置橘猫 / 黑猫 / 白猫 / 奶油 / 灰猫 / 狸花 / 三花等真实存在的猫色预设，或用取色器自由调**毛色**；像素风格、四肢、粉色腮红与道具（碗 / 面条 / 咖啡杯）始终保持不变。还能把配色一键**复制成配色码**发给朋友，对方粘贴即可得到同款猫咪（社交传猫！）
- **🧠 AI 大脑（可选）** — 接入轻量免费模型后，Coco 会真正"自主思考"：根据你的互动和它当前的心情/饱食度，自己挑动作并吐槽一句。默认关闭、完全离线；开了才联网，失败自动降级回本地文案。支持**本地 llama.cpp** 或任意 **OpenAI 兼容 API**（通义 / 豆包等）。
- **🖐 部位点击** — 点猫咪**脑袋**眯眼享受、点**肚子**翻身躲开、点**爪子**假装咬你，不同部位反应不一样（越摸越有戏）。
- **🐾 逗猫·追光点** — 一个会跳走的发光光点满屏乱跑，Coco 放下巡游撒腿去追，追到光点又蹦走，一局十几秒轻松又解压。
- **形象可完全自定义** — 精灵图按 `assets/sprites/<状态>/frame-N.png` 存放，想换形象直接替换图片即可（支持逐帧动画）

## 🧠 状态系统（怎么知道猫咪想要什么）

咖啡猫有 **四项需求**，会随时间自然变化，并且会主动让你知道它现在的状态：

| 需求 | 低了会怎样 | 对应互动 |
|---|---|---|
| 🍝 饱食 | 头顶冒 🍝，气泡喊「我饿啦~」 | 喂意大利宽面 |
| 🛁 清洁 | 头顶冒 🛁，气泡喊「身上脏脏的~」 | 洗澡 |
| 😴 精力 | 头顶冒 😴，气泡喊「好困呀~」 | 睡觉（睡觉中精力持续恢复） |
| 🎈 心情 | 头顶冒 🎈，气泡喊「好无聊呀~ 陪我玩嘛~」 | 玩毛线球 / 追光标 / 说嗨 |

**三种查看方式**：

1. **对话气泡** — 需求跌破阈值时猫咪会冒出气泡提示（每项 30 秒冷却，优先提示最紧急的一项）
2. **头顶小图标** — 只要还有需求偏低，头顶会一直挂着对应的小图标（🍝🛁😴🎈）
3. **状态面板** — 右键菜单或托盘菜单点「📊 状态」，展开四条彩色进度条（绿/黄/红），数值实时更新

互动与需求的对应关系：喂宽面+饱食、洗澡+清洁、睡觉+精力、玩毛线球/追光标+心情（但会消耗精力），点击/拖拽/喝咖啡也会小幅提升心情。

## 🤖 小助理功能

Coco 是你桌面上的小帮手：

- **🗑️ 吃掉文件** — 把任意文件/文件夹拖到猫身上，猫会"大口吃掉"并把它们**送入回收站**（可恢复）。有几点贴心细节：程序/系统文件（`.exe/.lnk/.bat/.cmd/.sys/.msi` 等，或在 `Program Files`、`Windows` 目录下的）会被**拒绝**（怕它吃坏肚子，避免误删关键文件）；吃太快会有**"吃撑"冷却**，歇一会儿才能再喂。
- **🧍 久坐提醒** — 当你连续工作（一段时间内无键盘/鼠标闲置）超过阈值，猫会伸个懒腰并弹出气泡提醒你起来活动。默认 60 分钟，可在托盘菜单的**「久坐提醒间隔」**里切换 30 / 60 / 90 分钟；提醒文案会随机轮换不单调。
- **🌦 天气预警** — 猫按 IP 粗略定位你所在地区，检查未来 6 小时的天气预报（Open-Meteo 免费接口，无需 API Key）。临近有雷暴、大雨、大雪、冻雨、浓雾或极端高温/低温会分级提醒；右键菜单点「**查看天气**」还能随时手动查当前天气。

提醒开关在系统托盘菜单的 **「🤖 小助理提醒」** 分组里。

## 🚀 本地运行

需要 [Node.js](https://nodejs.org) ≥ 18。

```bash
npm install     # 安装 Electron 依赖
npm start       # 启动桌面宠物
```

启动后宠物出现在屏幕右下角，你可以：

| 操作 | 效果 |
|---|---|
| 悬停宠物 | 猫偶尔歪头看你（节流，不打扰） |
| 单击宠物 | 猫咪挥手说嗨 |
| 双击宠物 | 猫咪高兴地蹦一下 |
| 拖动宠物 | 把猫咪拎起来拖到任意位置（松手会落地弹一下；拖到边缘会贴边吸附） |
| 右键宠物 | 弹出互动菜单（桌面巡游 / 喂宽面 / 洗澡 / 钓鱼 / 抓痒 / 查看天气 / 睡觉 / 退出等） |
| 托盘图标 | 常驻系统托盘，右键可触发桌面巡游、所有互动、外观设置（透明度/尺寸/全屏隐藏/边缘吸附）或退出 |

> 💾 **单机养成** — Coco 的**饱食 / 清洁 / 精力 / 心情**四维状态会保存在本地：喂它吃面/吃文件会变饱，洗澡变干净，玩毛线球/追光标会开心但会累，长时间不理它就会慢慢掉值并主动提醒你陪它。重启后状态延续，像一个需要你照顾的小家伙。

## 🎨 自定义形象（把猫换成你的）

应用是 **精灵图驱动** 的，改形象不需要碰代码：

```
assets/sprites/
├── idle/        frame-1..3 …  待机呼吸循环
├── idle-blink/  frame-1 …      闭眼眨眼帧
├── happy/       frame-1..2 …  说嗨/打招呼
├── drink/       frame-1..3 …  喝咖啡（吸饮循环）
├── feed/        frame-1..3 …  吃意大利宽面（咀嚼循环）
├── yarn/        frame-1..3 …  玩毛线球（扑球循环）
├── bath/        frame-1..3 …  洗澡（泡泡循环）
├── fishing/     frame-1 …      钓鱼
├── scratch/     frame-1 …      抓痒
├── stretch/     frame-1..3 …  伸懒腰
├── lookaround/  frame-1..3 …  东张西望
├── walk/        frame-1..6 …  走路循环
├── drag/        frame-1 …      被拖起
├── sleep/       frame-1..3 …  睡觉（呼吸循环）
└── core/        frame-1 …      核心形象（README 封面等）
```

- **逐帧动画（推荐）**：把同一状态多张帧命名成 `frame-1.png`、`frame-2.png`、…（最多 12 帧），应用会自动按该状态的帧率逐帧循环播放。走路/待机/吃喝/洗澡等核心状态都内置逐帧像素循环。
- **单帧图**：只放一张 `frame-1.png` 时，猫咪的灵动感由内置 CSS 动画（浮动/呼吸/摇摆）补足。
- **透明背景**：推荐用透明 PNG。若用带白底图，应用不会自动去底，最好先抠图（可用 `tools/process_sprites.py`）。

## 🎨 皮肤工坊（不用画画也能换肤）

右键菜单点「**🎨 皮肤工坊**」即可打开调色面板。换肤只改猫咪本体的**毛色**，像素风格、四肢、粉色腮红、以及手里的道具（碗、面条、咖啡杯）都原样保留（预设都是现实中真实存在的猫色，没有蓝猫、绿猫那种不存在的颜色）。

- **预设一键换**：🟠橘猫 · ⚫黑猫 · ⚪白猫 · 🟡奶油 · 🐭灰猫 · 🟤狸花 · 🧡三花
- **自定义调色**：直接拖动「毛色」取色器，实时预览
- **🎲 随机配色**：一键随机生成一套**现实中真实存在的猫色**（橘 / 虎斑 / 奶油 / 狸花棕 / 灰 / 近黑），不会出现蓝猫、绿猫那种不存在的不自然颜色
- **❤️ 我的配色**：保存并一键切回你最近调的那套颜色
- **↩ 恢复橘猫**：随时回到默认橘猫
- **配色码分享**：面板里的「配色码」（形如 `coco:橘猫#f6a64b`，带猫色名更好懂）可以一键**复制**；朋友在他们的 Coco 里点「粘贴」就能得到一模一样的猫咪。适合发朋友圈 / 小红书传猫～

> 配色方案保存在本地（`localStorage`），关闭应用后下次启动仍会记住。

## 🧠 AI 大脑（可选，让猫更贱更活）

右键宠物 →「🧠 AI 设置」即可开启。**默认关闭，完全离线**；开启后 Coco 会用大模型自己挑动作、说台词，变得更加慵懒、贱贱的、有记忆感。

> **不想配任何东西？没问题。** 不开 AI 时，Coco 自带一套"会看脸色"的本地贱猫性格：饿了 / 脏了 / 困了 / 无聊时，它对你的反应会不一样（比如饿得不行还喂咖啡，它会吐槽"咖啡不解饿！我要的是宽面！"），开箱就能感到它有性格。想上真 AI，点 AI 设置里的「✨ 免费开通（3 步）」领个免费 Key 粘进去就行，全程不用懂配置。

> **想真正免配置、还离线？** 点「🤖 用本地模型（离线·免配置）」——只需用[一键脚本](scripts/README.local-ai.md)装一次轻量本地模型（约 400MB），App 自动启动模型，**完全离线、免费、不用任何 API Key**。详见 [scripts/README.local-ai.md](scripts/README.local-ai.md)。

- **触发场景**（不是一直联网）：摸猫 / 双击 / 喂面 / 洗澡等互动、闲置时偶尔自言自语。
- **自主决策**：AI 返回 `{"action":"...","text":"..."}`，Coco 解析后**自己选动作**（洗脸 / 打哈欠 / 装睡 / 盯人 / 吐槽…）+ 弹一句话。动作只在待机时生效，不会打断巡游 / 追光标。
- **两种后端**（在面板里切换）：
  1. **本地 llama.cpp**（免费、断网可用、隐私最好）：`backend=本地`，接口填 `http://127.0.0.1:8080/v1`，模型名填你加载的 gguf 名（如 `qwen1.5-0.5b`）。
  2. **在线 OpenAI 兼容 API**（如通义千问 / 豆包免费额度）：`backend=在线`，接口填兼容地址 + API Key + 模型名。
- **容错降级**：断网 / Key 错 / 超时 / AI 乱输出 → 自动切回本地固定文案，**程序绝不会崩溃**。
- **防刷屏**：默认最小调用间隔 15 秒（可调 10/30/60 秒），不会疯狂消耗 token。
- **隐私**：API Key 只保存在本机 `prefs.json`，仅在你主动开启 AI 且触发事件时才发起请求，中间无中转服务器；传给模型的只有猫咪状态和简短对话文本，不读取电脑其他隐私。

### 快速接入示例（通义千问免费额度）
1. 去阿里云开通「通义千问」，拿到 `API-KEY` 与兼容接口地址（形如 `https://dashscope.aliyuncs.com/compatible-mode/v1`）。
2. 在「🧠 AI 设置」里：开启 → 后端选「在线 API」→ 填入接口地址、Key、模型名（如 `qwen-turbo`）→ 保存。

### 本地 llama.cpp 示例（完全离线）
1. 从 [llama.cpp](https://github.com/ggerganov/llama.cpp) 下载并启动：`./llama-server -m qwen1.5-0.5b-instruct-q4.gguf --port 8080`。
2. 「🧠 AI 设置」里后端选「本地 llama.cpp」→ 接口填 `http://127.0.0.1:8080/v1` → 模型名填你加载的名字 → 保存。
