🐾 DeskPet

An open-source desktop pet that lives on your computer screen.


## ✨ Features




- **Always-on top** — stays on your desktop while you work
- **Interactive** — click, drag, and play with your pet
- **Lightweight** — minimal resource usage
- **Cross-platform** — Windows, macOS, and Linux
- **Customizable** — add your own sprites, animations, and personalities
